# Together identity — raised fist revision

The **bold raised fist** is the primary identity, as requested. It represents solidarity and collective strength. The embrace is retired from the active application assets.

## Palette

- Navy `#0b1426`: primary background and text on light surfaces.
- Electric blue `#3058f4`: core action and fist symbol.
- Cyan `#21c9c4`: connection, activity and highlights.
- White `#ffffff`: key text and reversed mark.
- Light surface `#f1f4fa`: application backgrounds.

No orange is used in the new assets.

## Assets

- `public/brand/mark.svg`: transparent, text-free bold fist; use for navigation.
- `public/brand/fist-bold.svg`: explicit source copy of the primary symbol.
- `public/brand/wordmark.svg`: horizontal lockup; original vector lettering, no font dependency.
- `public/brand/logo-square.svg`: blue app tile with reversed white fist, 512 × 512.
- `public/brand/banner.svg`: 1600 × 900 vector cover for the demo/submission. Supporting copy uses a system sans-serif font.

The standalone symbol uses a vector mask to create clear finger and thumb creases. Keep it at least 24 CSS px high. Give it a minimum of 12 units of clear space on its 128-unit grid. Keep proportions unchanged. Use contextual HTML alt text; adjacent Together text permits an empty image alt.

The parent build regenerates the 192 and 512 px PWA icons from these revised vectors. Old exploratory assets are historical, not the current product identity.
